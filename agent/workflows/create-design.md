# Create design

Owner: design-agent. Shared rules: [AGENTS.md](../AGENTS.md).

1. Load [project-initialization](../skills/project-initialization/SKILL.md).
2. If references are needed, use [reference-research](../skills/reference-research/SKILL.md), then [reference-analysis](../skills/reference-analysis/SKILL.md).
3. Complete [design-planning](../skills/design-planning/SKILL.md), then [design-system](../skills/design-system/SKILL.md).
4. Choose [mobile-design](../skills/mobile-design/SKILL.md), [web-design](../skills/web-design/SKILL.md), or [dashboard-design](../skills/dashboard-design/SKILL.md); they route to layout and assets as needed.
5. Hand the returned target IDs to [validate-design](validate-design.md). Use [mockup-management](../skills/mockup-management/SKILL.md) only when presentation is requested.

# Update design

Owner: design-agent. Shared rules: [AGENTS.md](../AGENTS.md).

1. Inspect current scope with [figma-reading](../skills/figma-reading/SKILL.md) in the reader context.
2. Amend intent with [design-planning](../skills/design-planning/SKILL.md); use [component-management](../skills/component-management/SKILL.md) or [variant-management](../skills/variant-management/SKILL.md) for system changes.
3. Apply through [figma-sync](../skills/figma-sync/SKILL.md).
4. If interrupted, use [project-recovery](../skills/project-recovery/SKILL.md). Finish with [validate-design](validate-design.md).
